Что я узнала 
WHERE - фильрация данных
 Если SELECT отвечает на вопрос - что показать
 то WHERE отвечает на вопрос - какие строки оставить:
  SELECT name, signup_date
   FROM users
   WHERE name = 'Alice';
База операторов WHERE(равно '='/не равно '!=', больше '>' /меньше '<')
  SELECT *
   FROM users
   WHERE signup_date >= '2024-01-05';
Читается так: покажи пользователей зарегистрированных с 5 января и позже.
Несколько условий - AND(и)
  SELECT *
   FROM users
   WHERE signup_date >= '2024-01-01'
   AND signup_date <= '2024-01-07';
   При этом условии, в диапазон попадут только те пользователи, которые лежат в этом промежутке.(оба эти условия должны быть истинны)
Несколько условий - OR и IN(или). При этом условии, В результат попадут все строки, для которых хотя бы одно условие истинно.(достаточно выполнения хотя бы одного из этих условий)
Вариант через OR:
   SELECT *
   FROM users
   WHERE name = 'Alice'
   OR name = 'Bob';
Вариант через IN(предпочтительней):
   SELECT *
   FROM users
   WHERE name IN ('Alice', 'Bob')
Итог: когда один столбец и несколько равных значений, то выигрывает IN.
Вариант через OR:
   SELECT *
   FROM users
   WHERE name = 'Alice'
      OR name = 'Bob'
      OR name = 'Charlie'
Вариант через IN(предпочтительней):
   SELECT *
   FROM users
   WHERE name IN ('Alice', 'Bob', 'Charlie');
Итог: когда один столбец и много равных значений, то опять выигрывает IN.
Если условия про разные стобцы(не как у нас было на примере выше, только про имена, а например имена и даты):
   SELECT *
   FROM users
   WHERE name = 'Alice'
      OR signup_date > '2024-01-05';
Итог: тут у нас задача выбрать пользователей с именем Alice или зарегестрированных после 5 января. В данном случае у нас условия для разных столбцов и разные операторы(если есть >, <, != → IN не подходит). В таких случаях применима только OR.
