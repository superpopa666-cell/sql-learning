Тема 3-го дня это: ORDER BY и LIMIT
❗ORDER BY - сортировка результата:
- ASC (по умолчанию:сортировка от меньшего к большему(А-Я; 0-9)) - увеличение
ORDER BY signup_date ASC
- DECK (сортировка от большего к меньшему) - убывание
ORDER BY signup_date DESC
Сортировать можно как по одному столбцу, так и по нескольким:
ORDER BY signup_date DESC, name ASC
❗LIMIT - ограничение количества строк(используется почти всегда с ORDER BY)
LIMIT 5
❗Порядок: сначала сортируем(ORDER BY), потом ограничиваем(LIMIT)
Правильный порядок полноценной команды:
SELECT ...
FROM ...
WHERE ...
ORDER BY ...
LIMIT ...
